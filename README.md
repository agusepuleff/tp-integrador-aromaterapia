# 🌿 Proyecto Aromaterapia

Aplicación web desarrollada con React que permite visualizar productos de aromaterapia en una interfaz moderna, organizada y con una estética relajante.

---

## 🧾 Descripción

Este proyecto fue desarrollado como trabajo integrador con el objetivo de aplicar conocimientos de desarrollo frontend utilizando tecnologías modernas.

La aplicación presenta productos de aromaterapia mediante componentes reutilizables, organizados en distintas vistas, priorizando una experiencia de usuario clara y visualmente agradable.

---

## ⚙️ Instalación

1. Clonar el repositorio:

```bash
git clone <URL_DEL_REPO>
```

2. Ingresar al proyecto:

```bash
cd tp-integrador-aromaterapia
```

3. Instalar dependencias:

```bash
npm install
```

---

## ▶️ Ejecución en desarrollo

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```

Luego abrir en el navegador:

http://localhost:5173/

---

## 🏗️ Build del proyecto

Para generar una versión optimizada para producción:

```bash
npm run build
```

Esto generará la carpeta `dist/` con los archivos listos para deploy.

---

## 🧩 Funcionalidad

La aplicación incluye:

* Visualización de productos de aromaterapia
* Organización mediante componentes reutilizables
* Separación en páginas (pages) para mejor estructura
* Interfaz con diseño alineado a una estética natural
* Navegación simple entre secciones

---

## 🧱 Estructura del proyecto

```
src/
 ├── components/   # Componentes reutilizables
 ├── pages/        # Vistas principales
 ├── assets/       # Recursos (imágenes, etc.)
 └── App.tsx       # Componente raíz
```
